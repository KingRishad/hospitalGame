# Echoes of The Undying
Survive the zombies in an abandoned hospital. Use your weapons to deal with them and save the people in this game.

# System Requirements
OS: Windows 10/11  
Application: Visual Studio 2013

# How to build
1. Download the source code as a zip file.
2. Unzip the zip file.
3. Open the 'HospitalGame.sln' in Visual Studio 2013.
4. Build the project.
5. Enjoy.
